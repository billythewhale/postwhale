# v0.1.6

- PostWhale now imports and exports custom endpoints using `postwhale.<collectionName>.yml` in your service.
- Endpoint syncing is more complete: endpoints missing from YAML definitions can now be added automatically.
- Added safeguards to make creating new endpoints more reliable and prevent add-endpoint breakages.
- Improved endpoint management UX across the sidebar and request panel for smoother service/repository navigation.
